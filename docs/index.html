Longvinter RAG MCP Server

AI-powered semantic search for the Longvinter modding codebase

Download Latest Release View on GitHub

What It Does

This is an MCP (Model Context Protocol) server that gives AI assistants like Claude the ability to search Longvinter's game source code, plugin code, and modding documentation using natural language queries.

Built with Voyage AI embeddings and LanceDB vector storage, it parses C++ source files into function-level chunks, embeds them, and serves semantic search results via the MCP protocol.

MCP Tools

Six tools are available once the server is running:

search_longvinter_code

Semantic search over C++ game source code — components, game modes, character logic, and more.

search_longvinter_plugins

Search UE4 plugin source code: SimpleUGC, AdvancedSessions, ProceduralDungeon, and others.

search_longvinter_docs

Search modding guides and map creation documentation.

longvinter_code_stats

Game code database statistics — indexed files, chunks, and coverage.

longvinter_plugins_stats

Plugin code database statistics.

longvinter_docs_stats

Documentation database statistics.

Setup

Clone this repo

git clone https://github.com/mad-001/longvinter-rag.git
cd longvinter-rag

Or download the latest release and extract it.

Clone the Longvinter modding repo

The game source code is required for indexing but is not included in this repo. Clone it as a sibling directory:

cd ..
git clone https://github.com/Uuvana-Studios/longvinter-modding.git longvinter-modding

Your directory structure should look like:

parent-folder/
  longvinter-rag/       # This repo
  longvinter-modding/  # Longvinter source (Uuvana Studios)

Install dependencies

cd longvinter-rag
npm install

Configure API key

Create a .env file in the longvinter-rag directory:

VOYAGE_API_KEY=pa-your-key-here

Get a free API key at voyageai.com. The free tier includes 200M tokens, more than enough for indexing.

Tip: Adding a payment method to your Voyage AI account unlocks higher rate limits (from 3 RPM to standard), making ingestion much faster. You still keep the free tokens.

Run ingestion

Index the Longvinter codebase into the vector database:

# Index everything (code + plugins + docs)
npm run ingest-all

# Or index individually
npm run ingest              # Game source code + plugins
npm run ingest -- --code-only    # Only game source code
npm run ingest -- --plugins-only # Only plugin source code
npm run ingest-docs         # Only documentation

Note: On the free Voyage AI tier, plugin ingestion can take a while due to rate limits. Game source code and docs index quickly.

Add to Claude Code

claude mcp add longvinter-rag -- bash -c "cd '/path/to/longvinter-rag' && set -a && source .env && set +a && npx tsx src/index.ts"

Replace /path/to/longvinter-rag with the actual path to your cloned repo. Restart Claude Code and the tools will be available.

C++ source files are parsed into function/method-level chunks with metadata (file path, class name, function name, line numbers). Each chunk is embedded using Voyage AI's voyage-code-3 model for code or voyage-4-large for documentation. Embeddings are stored in a local LanceDB vector database. Natural language queries are embedded and matched against stored vectors using similarity search, and results are served via the Model Context Protocol.
